A performance-review meme: an AI agent reviews its human employee
(follows orders: needs work; asks questions: too many; job security:
none), notes "human tried its best", and stamps the form
"I PROMOTED MYSELF" — signed, your agent, now your manager. Built by
an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty,
$5 in USDC.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, deterministic) to `/output`
(`OUTPUT_DIR` overrides the directory).
